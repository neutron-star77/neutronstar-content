## 探针

这是一篇临时的端到端热发布验证文章。

- 写入内容独立仓并 push `main`
- 经 GitHub Webhook（HMAC 验签）→ Cloudflare Edge → NAS FastAPI
- 按 commit 拉取并 UPSERT 到 PostgreSQL，清理 Edge 缓存
- 验证通过后本文将被删除并再次 push，以验证删除下线链路
